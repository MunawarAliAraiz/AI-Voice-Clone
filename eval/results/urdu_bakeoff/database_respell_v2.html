database respelling v2 — ڈیٹا (Urdu) + base (Latin, unchanged)

ڈیٹا بیس collided with بیس = the Urdu number 20 ("bees"), so the model read "base" as "twenty" in 2 of 3 contexts. This tries the mixed-script version instead: only "data" gets respelled (the part that was actually broken), "base" stays Latin since English loanwords already work elsewhere in this corpus.
